# 반닫이 — 켜켜이 읽는 우리 건축

근정전·경회루의 책을 펼쳐 3D 모델과 공식 출처 기반 설명을 살펴보는 정적 웹입니다. 현재 웹의 진입점은 `dist/index.html` 하나입니다.

## 로컬 실행

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:4173/ 에 접속합니다. 별도 빌드는 필요 없습니다. Node.js가 있으면 `npm run check`로 소스 구문을 검사합니다.

## 조작

- 책 선택: 클릭, 좌우 키 또는 가로 드래그
- 건물: 드래그 회전, 우클릭 이동, 휠로 켜 펼치기, 핀치/Ctrl+휠 확대
- 켜 선택: 강조 및 설명. 홑겹: 선택한 켜 중심 보기
- 책 덮고 나가기: 정면 모델 → 밑그림 → 책 덮기

## 구성과 출처

- `dist/src/archive/`: 기록관 화면, 전환, 두 건물 등록, 경회루 설명·연못 연출
- `dist/src/layers.js`: 근정전 레이어 및 공식 출처
- `dist/models/`: 보존 대상인 건물별 웹용 3D 모델·텍스처
- `originals/`: 원본 참고 자료. 배포하지 않으며 FBX는 Git 제외
- `CONTENT_SOURCES.md`: 문화유산 설명의 공식 출처와 확인 범위
- `CONTINUE_HERE.md`: 이어서 작업할 때의 지침

이전 지도·드론 진입, 스크롤 산책, 단독 뷰어는 현재 웹에서 제거했습니다. 모델 조작용 분류와 연출은 공식 건축 분류나 실측 복원이 아닙니다. 설명은 공식 자료에서 확인된 사실만 싣습니다.

Git 커밋과 웹 배포는 별개입니다. 배포는 요청이 있을 때만 진행합니다.
